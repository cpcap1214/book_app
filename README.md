# 東京散步

SwiftUI 多頁面東京景點電子書 App，支援 iPhone 與 iPad。

收錄 11 個景點，提供景點介紹、地鐵站牌、精選景點、地區分類與官方導覽。

![東京散步](Screenshots/article/iphone-spots.jpg)

## 開啟專案

使用支援 iOS 26 SDK 的 Xcode 開啟 `TokyoGuide.xcodeproj`，選擇 iPhone 或 iPad 模擬器後執行。部署至實體裝置時，請自行設定簽署團隊。
